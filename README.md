# ❦ عُطرٌ وَ شِعر — Perfume Store

متجر عطور عربي (RTL)، أسود بحت / ذهبي معدني / Off-white، بتصميم Obsidian & Gold ناعم وبدون أي Grain أو Noise، ولوحة آدمن منفصلة. يعمل كواجهة ثابتة خفيفة وBackend على Supabase.

## التصميم المعدني الجديد (Obsidian & Gold)

- `styles.css`: أنماط الواجهة الأساسية.
- `luxury-theme.css`: تعديلات التصميم الأسود البحت والذهبي المعدني، تُحمّل بعد الملف الأساسي.
- `assets/metallic-corners.svg`: زخارف الزوايا الذهبية، مرسومة بتدرجات SVG ناعمة بدون أي صور تشويش أو حبيبات.
- تم حذف طبقة الحبيبات القديمة من `index.html`؛ الثيم يطبّق على صفحات الرئيسية والعطور والسلة والتسجيل والطلب ولوحة المشرف.
- الثيم يستجيب للهاتف، ويحترم خيار النظام لتقليل الحركة `prefers-reduced-motion`.

## الموجود في النسخة الأولى

- واجهة عربية متجاوبة مع الهاتف، صفحة رئيسية كلاسيكية، معرض عطور وبحث وتصنيفات.
- تسجيل دخول **زبون** وإنشاء حساب رسمي بالبريد الإلكتروني وكلمة مرور؛ وتسجيل دخول **آدمن** بصلاحيات منفصلة.
- إضافة وتعديل العطور: الاسم، الوصف، التصنيف، السعر بالدينار العراقي، المخزون، الصورة، وإظهار/إخفاء.
- حفظ السلة محليًا، تعديل الكميات، مراجعة تفاصيل الطلب، عنوان التوصيل والهاتف، ثم **تأكيد صريح قبل الإرسال**.
- **نقدًا عند الاستلام فقط**؛ الطلبات تظهر في لوحة المشرف مع التفاصيل والحالة، والزبون يستطيع متابعة طلباته.
- قاعدة بيانات فيها RLS، والتحقق من صلاحيات الإدارة واحتساب المجموع وفحص المخزون يحدث على الخادم داخل RPC لضمان عدم تزوير الأسعار.
- إرجاع المخزون عند إلغاء الطلب.

## الربط الفعلي (20 نوفمبر 2026)

- **تم إنشاء Supabase:** `Atr-Wa-Shir`، مشروع مستقل عن Veritasium.
- لوحة المشروع: https://supabase.com/dashboard/project/vptkiphvjtdevoomrgss
- **تم تطبيق** ملف `supabase/schema.sql` على قاعدة البيانات بنجاح، مع سياسات RLS للجداول الأربعة.
- **تم تحديث** `config.js` بمفتاح Supabase العام المخصص للمتصفح، ولا يحتوي على أي مفتاح سري.
- قاعدة المنتجات جديدة وفارغة حتى يضيف المشرف أول عطر.
- لإنشاء أول حساب آدمن: سجّل حسابك من واجهة الزبون، أكّد بريدك الإلكتروني إذا كان مطلوبًا، ثم نفّذ استعلام ترقية الدور المبيّن أدناه في SQL Editor. لا تسمح لواجهة العميل بتعيين دور المشرف.
- تذكّر تنزيل آخر نسخة من GitHub أو تنفيذ `git pull` على الفرع `atr-wa-shir-store` لتظهر إعدادات الاتصال الجديدة محليًا.

## تشغيل الواجهة

1. حمّل الملفات وافتح المجلد في VS Code.
2. شغّل خادمًا محليًا ثابتًا بدل فتح `index.html` مباشرة، مثل:
   ```bash
   python -m http.server 8000
   ```
3. افتح `http://localhost:8000`.
4. بدون ربط Supabase ستظهر مجموعة **عطور تجريبية للعرض فقط**؛ الحسابات والطلبات الحقيقية لن تعمل حتى يتم إعداد الخلفية.

## تفعيل قاعدة البيانات والحسابات الحقيقية

1. **تم مسبقًا:** إنشاء مشروع **Supabase مستقلًا خاصًا بالمتجر**.
2. **تم مسبقًا:** تطبيق الملف `supabase/schema.sql` على المشروع الجديد.
3. **تم مسبقًا:** ضبط `Project URL` ومفتاح `Publishable` في `config.js`:
   ```js
   window.ATR_CONFIG = {
     supabaseUrl: 'https://vptkiphvjtdevoomrgss.supabase.co',
     supabasePublishableKey: 'YOUR_PUBLIC_PUBLISHABLE_KEY'
   };
   ```
   ⚠️ ممنوع وضع `service_role` أو `secret key` هنا. المفتاح المنشور المقصود عام ولا يمنح صلاحيات إدارة بحد ذاته.
4. من **Authentication → URL Configuration** اضبط عنوان الموقع النهائي ضمن Site URL / Redirect URLs، وفعّل **Confirm email** إن رغبت بتأكيد البريد الإلكتروني.
5. أنشئ حسابًا عاديًا بالإيميل الذي سيكون للمشرف من واجهة التسجيل كزبون، وفعّل البريد وسجّل الدخول مرة واحدة.
6. من SQL Editor شغّل أمر ترقية ذلك الحساب فقط:
   ```sql
   update public.profiles set role = 'admin'
   where id = (select id from auth.users where email = 'admin@example.com');
   ```
   بدّل البريد ببريد حساب المشرف. بعدها سجّل الخروج وادخل بزر **دخول كآدمن**.
7. أضف العطور وصورها من لوحة التحكم؛ ستظهر تلقائيًا في المتجر.

## النشر

الموقع ثابت بدون بناء `npm`، ويمكن نشر الملفات على GitHub Pages أو Vercel (Static Site). عند نشره في مسار فرعي `https://.../repo/` تعمل روابط الملفات النسبية. أضف عنوان النشر إلى إعدادات Supabase Auth؛ وحافظ على تفعيل RLS. انشر `config.js` بالمفتاح **العام فقط**.

## تنظيم الملفات

- `index.html` — بنية الموقع والهوية.
- `styles.css` — تصميم كلاسيكي متجاوب، حركات وزجاجة عطر مرسومة بـ CSS.
- `app.js` — واجهة المتجر، تسجيل الدخول، السلة، الإدارة والطلبات.
- `config.js` — ربط مشروع Supabase (عام، لا يحتوي مفاتيح سرية).
- `supabase/schema.sql` — قاعدة البيانات، الصلاحيات، رفع الصور ودالة الطلبات.

## ملاحظات تنفيذية

- أسعار المنتجات بالدينار العراقي (IQD). رسوم التوصيل **غير مشمولة في إجمالي العطور**، ويحددها المشرف مع الزبون؛ لا توجد خدمة دفع إلكتروني.
- عينات العطور في وضع المعاينة ليست منتجات معروضة للبيع؛ تظهر فقط بدون ربط Backend.
- في حال تعديل سعر العطر بعد وضعه بالسلة، السعر المعتمد هو السعر الموجود في قاعدة البيانات وقت تأكيد الطلب.
- يتطلب هذا الإصدار الإنترنت لتحميل خطّي Amiri وTajawal وعميل Supabase من CDN. المتصفح يرجع لخطوط بديلة إن تعذر تحميل الخطوط.
- للحصول على قاعدة بيانات الطلبات الحية، يلزم إعداد Supabase؛ وجود الملفات على GitHub وحده لا يفعّل المصادقة.
